# Coffee Recipe Tracker

Private tracker for coffee recipes and brew results.

## GitHub Pages UI

This repo can also serve as a static GitHub Pages site.

- `index.html` - the browser UI
- `styles.css` - the visual design
- `app.js` - markdown parser, filters, and card rendering

The page reads `KAFFEEREZEPTE.md` directly, so the UI stays in sync with the log without a build step.

GitHub Pages is free for a normal static site on a public repo.
